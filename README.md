# TWWW MediaPal Proposal

Same presentation UI as **ATS / Reserve Trip** profile decks (`ats.css`, SlideShell, Lede, ProofPoints, paxes cards, chrome, Framer Motion).

## Run

```bash
cd TWWW-Proposal
npm install
npm run dev -- -p 3060
```

Open http://localhost:3060/deck
